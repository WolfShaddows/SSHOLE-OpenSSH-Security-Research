## LOAD 001 — Connection Handling

### Objective
Observe SSH connection handling and server-side behavior under controlled connection attempts.

### Observed result
The Alpine server logs recorded activation of a source-based IPv4 penalty.

Recorded event:

`srclimit_penalise: 172.23.0.4/32: activating ipv4 penalty of 15.700 seconds for penalty: connections without attempting authentication`

### Conclusion
A source-based penalty event was observed in this experiment.

This result is specific to the recorded execution and does not establish a universal connection threshold.

### Objective

### Execution

### Results

- No connection/protocol errors in the supplied results.
- No source penalty event in the supplied LOAD 002 logs.

### Conclusion
Sequential attempts completed with expected authentication rejection behavior.
